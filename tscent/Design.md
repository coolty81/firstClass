# TSCENT Design System

> 이 문서는 `tscent/index.html`, `tscent/css/main.css`, 공통 초기화 파일 `css/default.css`에 실제 작성된 디자인 규칙을 정리한 문서입니다.
>
> 기존 메인 페이지의 시각적 스타일을 서브 페이지에서도 일관되게 이어가기 위한 기준으로 사용합니다. 코드에서 확인되지 않는 값이나 동작은 임의로 추가하지 않습니다.

---

## 1. Project Overview

### 사이트 목적

메인 페이지의 콘텐츠 구성과 문구를 기준으로 볼 때, TSCENT는 차와 다구를 소개하고 판매하는 동시에 차와 관련된 문화·예술·교육·체험을 함께 전달하는 브랜드 웹사이트입니다.

메인 페이지는 다음과 같은 콘텐츠 흐름으로 구성되어 있습니다.

1. **Hero**: 브랜드 메시지, 문화 콘텐츠, 대표 상품을 슬라이드 배너로 소개
2. **Brand**: 티센트의 브랜드 성격과 운영 주체 소개
3. **Featured**: 대표 상품의 이미지와 상세 정보 소개
4. **Tea & Tools**: 잎차·다도구·선물세트 카테고리 소개
5. **Culture & Understanding**: 강의 등 차 문화 콘텐츠 소개
6. **Culture List**: 티코스·전시·체험 콘텐츠 안내
7. **Footer**: 브랜드 소개 문구, 연락처, 주요 정보 링크 제공

### 디자인 방향

- 차분하고 절제된 편집형 레이아웃을 사용합니다.
- 넓은 이미지와 충분한 여백으로 차와 공간의 분위기를 전달합니다.
- 검정·흰색을 기본으로 따뜻한 베이지, 차 녹색, 차 갈색을 포인트로 사용합니다.
- 과도한 장식보다 이미지, 제목, 설명문 사이의 위계와 정렬을 강조합니다.
- 상품 정보와 문화 콘텐츠를 같은 브랜드 경험 안에서 소개합니다.

위 내용은 메인 페이지의 실제 컬러 변수, 이미지 배치, 섹션 구성과 문구를 바탕으로 정리한 디자인 방향입니다.

## 2. Brand Identity

### 브랜드를 표현하는 시각 요소

| 요소 | 실제 구현에서 확인되는 특징 |
|---|---|
| 컬러 | 화이트와 블랙을 기본으로 웜 베이지, 티 그린, 티 브라운 사용 |
| 이미지 | 차와 관련된 공간·상품·문화 이미지를 큰 비율로 배치 |
| 레이아웃 | 넓은 콘텐츠 컨테이너, 좌우 분할, 이미지와 텍스트의 균형 |
| 타이포그래피 | Pretendard Variable, 비교적 절제된 굵기와 큰 제목 |
| 장식 | 얇은 경계선, 밑줄 링크, 단순한 테두리 버튼 |
| 분위기 | 여백이 많고 차분하며 정돈된 인상 |

### 브랜드 정체성 유지 규칙

- 새로운 페이지에서도 메인 페이지의 컬러 변수 체계를 우선 사용합니다.
- 차분한 분위기를 유지하고, 필요 이상의 강한 색상이나 장식을 추가하지 않습니다.
- 이미지는 콘텐츠의 성격을 전달하는 주요 요소이므로 임의의 장식 이미지로 대체하지 않습니다.
- 제목과 본문은 크기·굵기·색상 차이로 정보의 위계를 구분합니다.
- 섹션의 번호와 영문 라벨을 사용할 경우 메인 페이지의 `01 / BRAND` 형식과 같이 간결하게 표현합니다.

## 3. Design Principles

### 3-1. 여백으로 콘텐츠 구분하기

메인 페이지는 섹션에 넉넉한 상하 패딩을 적용합니다. 콘텐츠를 카드나 테두리로 모두 나누기보다 섹션 간 여백과 배경색 차이로 구분합니다.

- 데스크톱 섹션 기본 패딩: `100px 0`
- 1024px 이하 섹션 패딩: `80px 0`
- 모바일 섹션 패딩: 섹션 공통으로 별도 지정하지 않고, 개별 규칙을 유지합니다.

### 3-2. 이미지와 텍스트의 역할 분리

- 브랜드 소개: 텍스트와 큰 이미지를 좌우로 배치합니다.
- 대표 상품: 상품 이미지와 상세 설명을 나란히 배치합니다.
- 문화 콘텐츠: 이미지와 베이지 배경의 설명 영역을 결합합니다.
- 이미지에는 기본적으로 `object-fit: cover`를 적용해 영역을 채웁니다.

### 3-3. 정보 위계 유지

- 섹션 번호·영문 라벨은 보조 정보로 사용합니다.
- 섹션 제목은 본문보다 크게 표현합니다.
- 설명문은 보조 텍스트 색상으로 구분합니다.
- CTA는 텍스트 링크 또는 아웃라인 버튼으로 표현합니다.

### 3-4. 과한 컴포넌트 장식 지양

메인 페이지의 버튼과 링크는 단순한 테두리, 밑줄, 원형 화살표 중심입니다. 그림자, 강한 그라데이션, 과도한 라운드 카드 등 메인 페이지에서 사용하지 않는 장식은 기본 규칙으로 도입하지 않습니다.

## 4. Color System

색상은 `main.css`의 `:root`에서 정의된 변수를 우선 사용합니다.

### 4-1. Primitive Colors

| 변수명 | 값 | 용도 |
|---|---|---|
| `--color-white` | `#FFFFFF` | 기본 배경, 표면, 반전 텍스트 |
| `--color-black` | `#1E1E1E` | 주요 텍스트, 주요 액션, 푸터 배경 |
| `--color-tea-green` | `#6B7A5A` | 차 관련 강조색 |
| `--color-warm-beige` | `#F7F5EE` | 보조 배경 및 표면 |
| `--color-gray-600` | `#666666` | 보조 텍스트, 푸터 구분선 |
| `--color-gray-300` | `#DDDDDD` | 기본 경계선 |
| `--color-tea-brown` | `#B37A56` | 따뜻한 강조색 |

### 4-2. Semantic Colors

| 변수명 | 연결 값 | 적용 상황 |
|---|---|---|
| `--background-default` | `var(--color-white)` | 기본 페이지·섹션 배경 |
| `--background-subtle` | `var(--color-warm-beige)` | 차분한 구분 섹션 배경 |
| `--surface-default` | `var(--color-white)` | 기본 표면 |
| `--surface-subtle` | `var(--color-warm-beige)` | 문화 콘텐츠 설명 패널 등 |
| `--text-primary` | `var(--color-black)` | 제목과 주요 본문 |
| `--text-secondary` | `var(--color-gray-600)` | 보조 설명, 날짜, 번호 |
| `--text-inverse` | `var(--color-white)` | 어두운 배경 위 텍스트 |
| `--border-default` | `var(--color-gray-300)` | 기본 경계선 |
| `--action-primary` | `var(--color-black)` | 주요 액션 색상 |
| `--action-secondary` | `var(--color-tea-green)` | 보조 액션 색상 |
| `--action-disabled` | `var(--color-gray-300)` | 비활성 액션용 변수 |
| `--accent-tea` | `var(--color-tea-green)` | 카테고리 활성 표시 |
| `--accent-warm` | `var(--color-tea-brown)` | 따뜻한 강조색 |

### 4-3. 실제 적용 규칙

- 일반 페이지 배경은 `--background-default`를 사용합니다.
- 배경으로 섹션을 구분해야 할 때는 `--background-subtle`을 사용합니다.
- 주요 제목과 본문은 `--text-primary`, 보조 설명은 `--text-secondary`를 사용합니다.
- 어두운 푸터에서는 `--color-black` 배경과 `--text-inverse` 텍스트를 사용합니다.
- 카테고리의 활성 표시에는 `--accent-tea`를 사용합니다.
- 새 색상 코드를 임의로 추가하기보다 기존 변수를 먼저 조합합니다.

### 4-4. CSS에 직접 작성된 보조 색상

다음 값은 변수로 선언되어 있지 않지만 메인 CSS에 직접 사용되고 있습니다. 기존 화면과 동일한 표현이 필요한 경우에만 해당 맥락에서 사용합니다.

| 값 | 사용 위치 |
|---|---|
| `rgba(0, 0, 0, 0.15)` | Hero 배너 버튼 배경 |
| `#DDDDDD` | Swiper 비활성 페이지네이션 바 |
| `#666666` | Swiper 활성 페이지네이션 바 |
| `#B37A56` | 검색 메뉴를 열었을 때 검색 링크 색상 |
| `#666666` | 검색 메뉴를 닫았을 때 검색 링크 색상 |

## 5. Typography

### 5-1. Font Family

- CSS 변수: `--font`
- 정의값: `"Pretendard Variable", sans-serif`
- HTML에서 `../font/css/pretendardvariable.css`를 불러옵니다.
- 기본 본문은 `body`에 `font-family: var(--font)`로 적용됩니다.

### 5-2. 기본 기준

- `html`의 기준 글자 크기는 `16px`입니다.
- 별도 굵기가 지정되지 않은 본문은 브라우저 및 공통 스타일의 기본 굵기를 따릅니다.
- 제목은 주로 `font-weight: 500`을 사용하며, 가격 등 강조 정보에는 `600`을 사용합니다.
- 주요 큰 제목에는 음수 자간을 적용해 단정한 인상을 유지합니다.

### 5-3. 실제 글자 크기

| 요소 | 크기 | 굵기 | 행간·자간 |
|---|---:|---:|---|
| Hero 주요 문구 | `4.5rem` | 별도 지정 없음 | 별도 지정 없음 |
| Hero 보조 문구 | `1.5rem` | 별도 지정 없음 | `1.3` |
| 섹션 라벨 | `0.875rem` | 별도 지정 없음 | `1.3`, 자간 `0.02em` |
| 브랜드 제목 | `clamp(3rem, 3.1vw, 5rem)` | `500` | `1.12`, 자간 `-0.04em` |
| 섹션 제목 | `clamp(2.8rem, 4vw, 3.5rem)` | `500` | `1.1`, 자간 `-0.04em` |
| 브랜드 리드 문장 | `1.25rem` | 별도 지정 없음 | `1.55` |
| 일반 설명문 | `1rem` | 별도 지정 없음 | 영역별 `1.5`~`1.75` |
| 상품 제목 | `2rem` | `500` | `1.25` |
| 상품 가격 | `1.25rem` | `600` | 별도 지정 없음 |
| 상품 번호·항목 번호 | `0.875rem` | 별도 지정 없음 | `1` |
| 작은 영문 라벨 | `0.8rem` | 별도 지정 없음 | `1.2` |
| Footer 기본 텍스트 | `1.125rem` | `400` | `1` |

### 5-4. 모바일 글자 크기 조정

- Hero 보조 문구: `clamp(0.8rem, 2vw, 1.2rem)`
- Hero 주요 문구: `clamp(1.6rem, 6vw, 3rem)`
- 브랜드 제목: 640px 이하에서 `2.8rem`
- 상품 제목: 640px 이하에서 `1.65rem`
- Footer 텍스트: 640px 이하에서 `0.95rem`, 행간 `1.4`

### 5-5. 서브 페이지 적용 방법

- 섹션 라벨, 페이지 제목, 본문, 보조 설명의 위계를 유지합니다.
- 큰 제목에 임의의 굵은 폰트나 과도한 자간을 적용하지 않습니다.
- 본문은 보조 텍스트와 구분하되, 설명의 가독성을 우선합니다.
- 위 표에 없는 크기는 메인 페이지에서 사용된 유사한 역할의 요소를 기준으로 선택하고, 새로운 규칙이 필요하면 별도로 합의합니다.

## 6. Layout & Spacing

### 6-1. 공통 컨테이너

메인 콘텐츠의 공통 클래스는 `.section-inner`입니다.

| 화면 조건 | 너비 규칙 |
|---|---|
| 기본 | `width: min(1720px, calc(100% - 200px))` |
| 1200px 이하 | `width: min(100% - 120px, 1720px)` |
| 1024px 이하 | `width: calc(100% - 100px)` |
| 640px 이하 | `width: calc(100% - 40px)` |

- 좌우 여백은 컨테이너의 `margin: 0 auto`로 균등하게 유지합니다.
- Footer의 `.footer-inner`도 기본적으로 최대 너비 1720px, 좌우 200px을 제외한 너비를 사용합니다.
- 1024px 이하 Footer 컨테이너는 좌우 50px, 640px 이하에서는 좌우 20px 여백을 사용합니다.

### 6-2. Header와 Hero

- Header는 `position: fixed`, 높이 `85px`, 좌우 패딩 `100px`입니다.
- Header는 `z-index: 10`으로 화면 상단에 고정됩니다.
- Hero Swiper는 기본 높이 `760px`입니다.
- 1024px 이하에서는 Hero 높이가 `100dvh`로 바뀝니다.
- Hero 배너의 텍스트 그룹은 절대 위치로 배치하고, 데스크톱에서는 왼쪽 `100px`에서 시작합니다.

### 6-3. 섹션 간격

- 주요 섹션의 기본 상하 패딩은 `100px`입니다.
- 1024px 이하에서는 주요 섹션 패딩을 `80px 0`으로 조정합니다.
- 주요 콘텐츠 간격은 각 섹션의 실제 관계에 맞춰 `20px`, `34px`, `40px`, `60px`, `64px` 등으로 지정되어 있습니다.
- 이 간격값을 모든 컴포넌트에 일괄 적용하지 말고, 동일한 역할의 요소에만 재사용합니다.

### 6-4. Grid와 Flex 사용 규칙

| 레이아웃 | 구현 방식 | 사용 상황 |
|---|---|---|
| Header | Flex | 로고·메인 메뉴와 우측 유틸리티 메뉴를 양쪽에 배치 |
| Hero 텍스트 | Flex column | 라벨·제목·설명·버튼을 세로로 정렬 |
| Brand | Grid `1fr 800px` | 브랜드 텍스트와 큰 이미지의 2열 구성 |
| Featured Product | Grid `800px minmax(0, 579px)` | 상품 이미지와 설명의 2열 구성 |
| Tea Feature | Grid `495px 800px` | 차 소개 텍스트와 이미지의 2열 구성 |
| Culture Feature | Grid `756px minmax(0, 1fr)` | 이미지와 설명 패널의 2열 구성 |
| Footer Top | Grid `199px 312px 63px 125px` | 브랜드·연락처·정보 링크를 열로 분리 |
| Culture List | Grid | 번호·설명·원형 링크를 한 줄에 정렬 |

### 6-5. 이미지 규칙

- 이미지 요소는 `display: block`, `width: 100%`, `height: 100%`, `object-fit: cover`를 사용합니다.
- 브랜드·대표 상품·차 이미지에는 `border-radius: 14px`가 적용됩니다.
- 문화 이미지에는 위 이미지 그룹의 공통 규칙과 달리 별도 라운드가 지정되어 있지 않습니다.
- 이미지 비율과 높이는 콘텐츠 영역의 목적에 맞춰 지정하며, 모바일에서는 비율 기반으로 바뀝니다.

## 7. Components

### 7-1. Header / GNB

- Header는 화면 상단에 고정되는 흰색 영역입니다.
- 왼쪽 그룹에는 로고와 주요 메뉴가 배치됩니다.
  - 차·도구
  - 문화·이해
  - About
  - Notice
- 오른쪽 그룹에는 검색, 로그인, 회원가입, 장바구니, 메뉴 아이콘이 배치됩니다.
- 첫 번째 메뉴 그룹은 Flex와 `gap: 34px`를 사용합니다.
- 오른쪽 메뉴 그룹은 `font-size: 14px`, `gap: 20px`를 사용합니다.
- 1024px 이하에서는 텍스트 메뉴를 숨기고 메뉴 아이콘을 표시합니다.

### 7-2. Search Panel

- Header 아래에 위치하며 `#search`로 구현되어 있습니다.
- 높이는 `100px`, 상단 위치는 Header 높이에 맞춘 `85px`입니다.
- 상단 경계선은 `1px solid var(--border-default)`입니다.
- 검색 입력창은 너비 `50dvw`이며 하단 경계선으로 구분합니다.
- 검색 영역에는 관심 키워드 목록이 함께 표시됩니다.
- 기본 상태는 HTML의 인라인 스타일에 따라 숨김 상태입니다.

### 7-3. Mobile Navigation

- `#moMenu`는 화면 오른쪽에 고정되는 모바일 메뉴 패널입니다.
- 너비는 `70vw`, 높이는 `100vh`입니다.
- 내부 메뉴는 Flex column, `gap: 32px`로 정렬합니다.
- 메뉴 패널은 `transform: translateX(100%)`에서 화면 안쪽으로 이동하며, 전환 시간은 `1s`입니다.
- 1024px 이하에서 Header의 메뉴 아이콘이 표시됩니다.

### 7-4. Hero Slider

- Swiper 라이브러리를 사용합니다.
- 가로 방향이며 `loop: true`로 반복됩니다.
- 자동 재생 간격은 `5000ms`입니다.
- 좌우 이동 버튼과 클릭 가능한 페이지네이션을 제공합니다.
- 페이지네이션은 둥근 점이 아닌 너비 `34px`, 높이 `2px`의 가로 막대입니다.
- 비활성 막대는 `#DDDDDD`, 활성 막대는 `#666666`입니다.
- 1024px 이하에서는 PC용 이미지 대신 모바일용 이미지를 표시합니다.

### 7-5. Section Label

- 클래스: `.section-label`
- 블록 요소로 표시합니다.
- 색상은 `var(--text-secondary)`, 크기는 `0.875rem`, 행간은 `1.3`, 자간은 `0.02em`입니다.
- 섹션 제목 위에 번호와 영문 카테고리를 표시할 때 사용합니다.

### 7-6. Text Link

- 클래스: `.text-link`
- Inline Flex로 텍스트와 아이콘 문자를 정렬합니다.
- 너비는 콘텐츠에 맞춘 `fit-content`입니다.
- 주요 텍스트 색상을 사용하고 하단에 `1px` 밑줄을 표시합니다.
- 밑줄과 텍스트 사이에는 `4px`의 아래 패딩을 둡니다.
- 브랜드 소개, 섹션 전체 보기, 카테고리 전체 보기 등에 사용합니다.

### 7-7. Outline Button

- 클래스: `.outline-btn`
- Inline Flex로 버튼 텍스트를 가로·세로 중앙 정렬합니다.
- 최소 너비 `154px`, 높이 `50px`, 좌우 패딩 `20px`입니다.
- 테두리는 `1px solid var(--text-primary)`, 모서리는 `6px)입니다.
- 상품 상세 보기와 문화 콘텐츠 자세히 보기에 사용합니다.

### 7-8. Category Tabs

- 클래스: `.category-tabs`
- Flex로 가로 배치하며 기본 간격은 `30px)입니다.
- 아래쪽에 `1px solid var(--border-default)` 경계선을 둡니다.
- 기본 링크는 보조 텍스트 색상입니다.
- `.is-active` 상태는 주요 텍스트 색상과 굵기 `600`을 사용합니다.
- 활성 탭 아래에는 `2px) 높이의 `var(--accent-tea)` 선을 표시합니다.
- 640px 이하에서는 가로 스크롤을 허용하고 줄바꿈하지 않습니다.

### 7-9. Culture List / Round Arrow

- 문화 목록은 `ul.culture-list`로 구성합니다.
- 목록 전체의 위쪽과 각 항목 아래쪽에 `2px solid var(--border-default)` 선을 사용합니다.
- 각 항목은 번호·설명·링크의 Grid 구조입니다.
- 화살표 링크는 `.round-arrow`를 사용하며 기본 크기는 `60px × 60px), 테두리는 `1px solid var(--text-primary)`, 원형 모서리입니다.
- 1024px 이하에서는 `50px × 50px`, 640px 이하에서는 설명 아래쪽으로 이동합니다.

### 7-10. Footer

- 클래스: `.site-footer`
- 배경은 `var(--color-black)), 텍스트는 `var(--text-inverse)`입니다.
- 내부 콘텐츠는 `.footer-inner`로 최대 너비 `1720px`를 유지합니다.
- 상단은 브랜드·연락처·두 개의 링크 그룹으로 구성된 Grid입니다.
- 브랜드 로고는 흰색으로 보이도록 `filter: brightness(0) invert(1)`을 적용합니다.
- 하단에는 `2px) 높이의 회색 구분선과 저작권 문구가 있습니다.

### 컴포넌트 재사용 원칙

- 동일한 역할의 링크는 `.text-link` 또는 `.outline-btn` 중 목적에 맞는 패턴을 사용합니다.
- 단순한 이동 링크를 버튼처럼 과하게 꾸미지 않습니다.
- 새 카드가 필요하다면 기존 메인 페이지의 이미지·텍스트 분할 방식을 우선 참고합니다. 메인 페이지에는 일반적인 반복 상품 카드 그리드가 구현되어 있지 않으므로, 임의로 카드 스타일을 표준 컴포넌트라고 간주하지 않습니다.

## 8. Interaction

### 8-1. 현재 구현된 동작

| 요소 | 동작 | 구현 근거 |
|---|---|---|
| Hero Slider | 5초 간격 자동 재생, 반복, 좌우 이동, 페이지네이션 클릭 | Swiper 설정 |
| 검색 | 검색 메뉴 열기·닫기 | `showPanel()` |
| 검색 링크 | 열림 상태에서 차 갈색, 닫힘 상태에서 회색으로 변경 | 인라인 JavaScript |
| 모바일 메뉴 | 메뉴 아이콘을 누르면 패널이 화면 안으로 이동, 다시 누르면 닫힘 | `showMenu()`, transform |
| 카테고리 탭 | 첫 번째 항목에 활성 표시 | `.is-active` 클래스 |

### 8-2. Hover / Focus / Active 상태

- `main.css`에는 링크·버튼에 대한 별도의 `:hover`, `:focus`, `:active` 디자인 규칙이 명시적으로 확인되지 않습니다.
- 따라서 메인 페이지에서 모든 요소의 Hover 색상이나 Active 애니메이션이 공통으로 정의되어 있다고 가정하지 않습니다.
- 공통 `default.css`에는 `:focus`의 기본 외곽선을 제거하고 `:focus-visible`에 `2px solid currentColor`, `outline-offset: 2px`를 적용하는 규칙이 있습니다.
- `default.css`의 `prefers-reduced-motion: reduce` 규칙은 애니메이션·전환 시간을 `0.01ms`로 줄입니다.
- 서브 페이지에서 Hover 효과가 필요하다면 링크인지 버튼인지 역할을 먼저 구분하고, 키보드 사용자를 위한 `:focus-visible`도 함께 설계합니다. 이때 메인 페이지에 없는 효과를 기존 규칙인 것처럼 표현하지 않습니다.

### 8-3. Transition

- 모바일 메뉴 `#moMenu`에는 `transition: 1s`가 적용되어 있습니다.
- 그 외 일반 링크와 아웃라인 버튼에는 별도의 transition 규칙이 명시되어 있지 않습니다.
- 새로운 인터랙션을 추가할 경우 움직임은 기능을 이해하는 데 필요한 범위로 제한하고, 모션 감소 설정을 고려합니다.

### 8-4. 인터랙션 유지 규칙

- 링크와 버튼은 시각적 상태만이 아니라 실제 목적과 동작이 일치해야 합니다.
- 현재 메인 HTML에는 `href="#"`인 링크가 다수 있으므로, 실제 서브 페이지를 제작할 때는 해당 링크의 목적지와 기능을 별도로 연결해야 합니다.
- 기존 메인 페이지의 링크 목적지를 임의로 변경하지 않습니다.

## 9. Responsive Rules

현재 CSS에서 확인되는 주요 분기점은 `1200px`, `1024px`, `640px`입니다.

### 9-1. 1200px 이하

- 콘텐츠 컨테이너 너비를 `min(100% - 120px, 1720px)`로 변경합니다.
- Brand, Featured Product, Tea Feature, Culture Feature의 2열 Grid를 1열로 변경합니다.
- 이미지 너비는 컨테이너에 맞추고 최대 너비 `800px`를 유지합니다.
- Culture Card의 최소 높이를 해제합니다.

### 9-2. 1024px 이하

- PC용 Hero 이미지를 숨기고 모바일용 이미지를 표시합니다.
- Hero 높이는 `100dvh`로 변경합니다.
- Header 좌우 패딩은 `50px)입니다.
- Header의 텍스트 메뉴는 숨기고 메뉴 아이콘을 표시합니다.
- Hero 텍스트는 왼쪽 기준 `0), 좌우 패딩 `50px)로 변경합니다.
- 주요 섹션은 최소 높이를 해제하고 상하 패딩을 `80px)로 조정합니다.
- 브랜드·상품·차 이미지는 `4 / 3` 비율을 사용합니다.
- 문화 이미지는 `4 / 5` 비율을 사용합니다.
- Culture Card 패딩은 `64px 50px)입니다.
- Footer는 2열 Grid로 바뀌고 행 간격은 `48px)입니다.

### 9-3. 640px 이하

- 콘텐츠 컨테이너는 좌우 `20px)을 제외한 너비를 사용합니다.
- 브랜드 제목은 `2.8rem`, 상품 제목은 `1.65rem)입니다.
- 섹션 헤더는 블록 형태로 바뀌고 링크는 위쪽 `24px) 간격을 둡니다.
- 카테고리 탭은 간격 `20px), 가로 스크롤, 줄바꿈 없음으로 처리합니다.
- Culture Card 패딩은 `48px 30px)입니다.
- 문화 목록은 2열 구조로 바뀌고 원형 화살표는 설명 아래 행으로 이동합니다.
- Footer는 1열 구조로 바뀌며 내부 간격은 `36px), 주요 텍스트 크기는 `0.95rem)입니다.

### 반응형 제작 원칙

- 메인 페이지의 3개 분기점과 컨테이너 여백을 우선 기준으로 사용합니다.
- 데스크톱에서 좌우로 배치된 콘텐츠는 좁은 화면에서 세로로 쌓이도록 설계합니다.
- 이미지에는 모바일에서 별도의 비율이 필요한지 확인합니다.
- 메뉴·탭·푸터 등 가로 공간을 많이 사용하는 요소는 모바일에서 숨김, 스크롤, 열 재배치 중 적합한 방식을 선택합니다.
- 메인 페이지에 없는 추가 분기점은 실제 콘텐츠가 깨지는 지점을 확인한 뒤 결정합니다.

## 10. Do & Don't

### Do

- [ ] 색상은 `:root`의 Primitive·Semantic 변수를 우선 사용합니다.
- [ ] 기본 글꼴은 `--font`를 사용합니다.
- [ ] 콘텐츠 폭과 좌우 여백은 `.section-inner` 규칙을 기준으로 맞춥니다.
- [ ] 섹션 제목·영문 라벨·본문의 정보 위계를 유지합니다.
- [ ] 이미지와 텍스트의 역할을 분명하게 나누고 충분한 여백을 확보합니다.
- [ ] 링크는 텍스트 링크, 테두리 버튼, 원형 화살표 등 기존 패턴 중 목적에 맞는 형태를 사용합니다.
- [ ] 1200px, 1024px, 640px 반응형 규칙을 확인합니다.
- [ ] 키보드 포커스와 모션 감소 설정을 고려합니다.
- [ ] 기존 메인 페이지의 HTML 구조와 CSS를 불필요하게 변경하지 않습니다.

### Don't

- [ ] 기존 변수와 관계없는 새로운 브랜드 컬러를 근거 없이 추가하지 않습니다.
- [ ] 메인 페이지에 없는 그림자·그라데이션·과도한 장식 효과를 기본 스타일로 만들지 않습니다.
- [ ] 모든 콘텐츠를 같은 모양의 카드 안에 넣지 않습니다.
- [ ] 큰 제목과 본문에 임의의 폰트·굵기·자간 규칙을 섞지 않습니다.
- [ ] 데스크톱의 2열 레이아웃을 모바일에서도 그대로 유지하지 않습니다.
- [ ] Hover·Active 동작이 현재 구현되어 있다고 추측하지 않습니다.
- [ ] 실제 목적지가 정해지지 않은 링크를 임의의 외부 사이트로 연결하지 않습니다.
- [ ] 메인 페이지의 디자인을 서브 페이지 제작 과정에서 임의로 바꾸지 않습니다.

## Implementation Notes

### 확인한 파일

- `tscent/index.html`: 메인 페이지의 HTML 구조와 콘텐츠
- `tscent/css/main.css`: TSCENT 메인 페이지의 컬러·타이포그래피·레이아웃·컴포넌트·반응형 스타일
- `css/default.css`: 전역 Reset, 기본 접근성 포커스, 모션 감소 규칙
- `tscent/img/`: 로고, 메뉴 아이콘, Hero 및 섹션 이미지 리소스

### 현재 확인 범위와 한계

- 현재 `tscent` 최상위 폴더에는 메인 페이지 `index.html`과 `css/main.css`, `img` 리소스가 확인됩니다.
- 서브 페이지의 실제 구현은 확인되지 않았으므로, 이 문서는 메인 페이지를 기준으로 한 공통 디자인 가이드입니다.
- Header의 메뉴 링크와 콘텐츠 링크 중 일부는 현재 `href="#"`로 되어 있습니다. 실제 페이지 이동 구조는 서브 페이지 제작 시 별도로 연결해야 합니다.
- Hover·Active 디자인은 별도 규칙이 확인되지 않으므로, 기존 디자인 규칙으로 단정하지 않았습니다.
